## 4. 字符集修复记录

浏览器登录后，动态菜单、用户昵称、部门名称出现中文乱码；静态页面文案正常。

排查结果：

- MySQL 表中初始化数据已经是乱码字节，例如 `若依` 被存为 `C3A8E280B9C2A5C3A4C2BEC29D`。
- 原因是 Docker 初始化导入 SQL 时，MySQL 客户端没有按 `utf8mb4` 读取 SQL 文件。

修复动作：

- 已备份修复前数据库到 `infra/backups/ry-vue-before-charset-fix-20260418-224827.sql`。
- 已新增 MySQL 字符集配置 `infra/mysql/conf.d/charset.cnf`。
- 已在 `infra/docker-compose.yml` 中挂载该配置，避免后续重建数据库时复发。
- 已使用 `--default-character-set=utf8mb4` 重新导入 `backend/sql/quartz.sql` 和 `backend/sql/ry_20260417.sql`。

修复后抽样确认：

```text
admin nick_name: 若依, hex: E88BA5E4BE9D
menu 1 menu_name: 系统管理, hex: E7B3BBE7BB9FE7AEA1E79086
```
