## 2. 前端环境变量

### `.env.development`

开发环境使用：

```env
VITE_APP_TITLE = 若依管理系统
VITE_APP_ENV = 'development'
VITE_APP_BASE_API = '/dev-api'
```

含义：

| 变量 | 当前值 | 作用 |
| --- | --- | --- |
| `VITE_APP_TITLE` | `若依管理系统` | 浏览器标题和系统标题 |
| `VITE_APP_ENV` | `development` | 标记当前为开发环境 |
| `VITE_APP_BASE_API` | `/dev-api` | 前端请求接口时使用的基础路径 |

开发环境下，前端请求 `/dev-api`，再由 Vite 代理到后端：

```text
http://localhost:8080
```

代理配置在：

```text
frontend/vite.config.js
```

当前关键配置：

```js
const baseUrl = 'http://localhost:8080'

server: {
  port: 5173,
  host: true,
  open: false,
  proxy: {
    '/dev-api': {
      target: baseUrl,
      changeOrigin: true,
      rewrite: (p) => p.replace(/^\/dev-api/, '')
    }
  }
}
```

### `.env.production`

生产构建使用：

```env
VITE_APP_TITLE = 若依管理系统
VITE_APP_ENV = 'production'
VITE_APP_BASE_API = '/prod-api'
VITE_BUILD_COMPRESS = gzip
```

含义：

| 变量 | 当前值 | 作用 |
| --- | --- | --- |
| `VITE_APP_ENV` | `production` | 标记当前为生产环境 |
| `VITE_APP_BASE_API` | `/prod-api` | 生产环境接口前缀 |
| `VITE_BUILD_COMPRESS` | `gzip` | 构建时生成 gzip 压缩文件 |

生产环境通常由 Nginx 将 `/prod-api/` 代理到后端：

```text
http://127.0.0.1:8080/
```

示例配置在：

```text
infra/nginx.conf
```

### `.env.staging`

预发布构建使用：

```env
VITE_APP_TITLE = 若依管理系统
VITE_APP_ENV = 'staging'
VITE_APP_BASE_API = '/stage-api'
VITE_BUILD_COMPRESS = gzip
```

预发布环境用于模拟生产部署，但接口前缀使用 `/stage-api`，方便和正式环境区分。

## 3. 后端基础配置

后端主配置文件：

```text
backend/ruoyi-admin/src/main/resources/application.yml
```

### 项目文件路径

```yaml
ruoyi:
  profile: /home/lemon/test-project/uploads
```

用途：

```text
上传文件、头像、下载文件等本地资源目录
```

当前目录：

```text
/home/lemon/test-project/uploads
```

如果换机器或换目录，需要同步修改这个路径，并确保目录可写。

### 后端端口

```yaml
server:
  port: 8080
  servlet:
    context-path: /
```

含义：

| 配置 | 当前值 | 作用 |
| --- | --- | --- |
| `server.port` | `8080` | 后端 HTTP 端口 |
| `server.servlet.context-path` | `/` | 后端应用访问路径 |

如果把后端端口改成 `9090`，需要同步修改：

```text
frontend/vite.config.js
infra/nginx.conf
```

### Redis 配置

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      database: 0
      password:
      timeout: 10s
```

含义：

| 配置 | 当前值 | 作用 |
| --- | --- | --- |
| `host` | `localhost` | Redis 地址 |
| `port` | `6379` | Redis 端口 |
| `database` | `0` | Redis 数据库编号 |
| `password` | 空 | Redis 密码，当前未设置 |
| `timeout` | `10s` | 连接超时时间 |

当前 Redis 由 Docker Compose 启动，没有密码。

### Token 配置

```yaml
token:
  header: Authorization
  secret: abcdefghijklmnopqrstuvwxyz
  expireTime: 30
```

含义：

| 配置 | 当前值 | 作用 |
| --- | --- | --- |
| `token.header` | `Authorization` | 前端请求携带 token 的请求头 |
| `token.secret` | `abcdefghijklmnopqrstuvwxyz` | JWT 签名密钥 |
| `token.expireTime` | `30` | token 有效期，单位分钟 |

上线前建议修改 `token.secret`，不要继续使用默认值。

## 4. 后端数据库配置

数据库配置文件：

```text
backend/ruoyi-admin/src/main/resources/application-druid.yml
```

当前主库配置：

```yaml
spring:
  datasource:
    druid:
      master:
        url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=GMT%2B8
        username: ruoyi
        password: ruoyi123456
```

含义：

| 配置 | 当前值 | 作用 |
| --- | --- | --- |
| 数据库地址 | `localhost:3306` | MySQL 地址和端口 |
| 数据库名 | `ry-vue` | RuoYi 使用的数据库 |
| 用户名 | `ruoyi` | 后端连接 MySQL 的账号 |
| 密码 | `ruoyi123456` | 后端连接 MySQL 的密码 |
| `useSSL` | `false` | 本地开发关闭 SSL |
| `allowPublicKeyRetrieval` | `true` | 兼容 MySQL 8 公钥认证 |
| `serverTimezone` | `GMT+8` | 数据库时区 |

如果修改 Docker Compose 中的 MySQL 用户名或密码，需要同步修改这里。

### Druid 管理页面

当前 Druid 页面配置：

```yaml
statViewServlet:
  enabled: true
  url-pattern: /druid/*
  login-username: ruoyi
  login-password: 123456
```

访问地址：

```text
http://localhost:8080/druid/
```

上线前建议：

- 修改 `login-username`
- 修改 `login-password`
- 配置访问白名单 `allow`
- 或在生产环境关闭 Druid 管理页面

## 5. Docker Compose 配置

Docker Compose 文件：

```text
infra/docker-compose.yml
```

### MySQL

当前配置：

```yaml
MYSQL_ROOT_PASSWORD: root123456
MYSQL_DATABASE: ry-vue
MYSQL_USER: ruoyi
MYSQL_PASSWORD: ruoyi123456
TZ: Asia/Shanghai
```

端口映射：

```yaml
ports:
  - "3306:3306"
```

初始化 SQL：

```yaml
volumes:
  - ../backend/sql:/docker-entrypoint-initdb.d:ro
```

说明：

MySQL 容器首次创建数据卷时，会自动执行 `backend/sql/` 目录下的 SQL 文件。当前会导入 RuoYi 初始化表和数据。

如果数据卷已经存在，重启容器不会重复导入 SQL。

### Redis

当前配置：

```yaml
image: redis:7-alpine
command: ["redis-server", "--appendonly", "yes"]
ports:
  - "6379:6379"
```

说明：

当前 Redis 没有设置密码，适合本地开发。生产环境建议设置密码，并同步修改后端 `application.yml` 中的 Redis 密码。

## 7. Maven 代理配置

Maven 配置文件：

```text
backend/.mvn/settings.xml
```

当前代理：

```xml
<host>127.0.0.1</host>
<port>7897</port>
```

作用：

```text
让 Maven 下载依赖时走本地代理，避免依赖下载超时。
```

如果你的代理端口变化，比如改成 `7890`，需要把两个 proxy 节点里的端口都改成：

```xml
<port>7890</port>
```

如果当前网络不需要代理，可以将 `active` 改为 `false`，或使用自己的 Maven settings。

## 8. 常见修改场景

### 修改前端开发端口

修改：

```text
frontend/vite.config.js
```

找到：

```js
server: {
  port: 5173
}
```

改完后重启前端：

```bash
./scripts/stop-frontend.sh
./scripts/start-frontend.sh
```

### 修改后端端口

修改：

```text
backend/ruoyi-admin/src/main/resources/application.yml
```

找到：

```yaml
server:
  port: 8080
```

同时修改：

```text
frontend/vite.config.js
infra/nginx.conf
```

然后重新构建并重启后端：

```bash
./scripts/build-backend.sh
./scripts/stop-backend.sh
./scripts/start-backend.sh
```

### 修改数据库密码

需要同步修改两个地方：

```text
infra/docker-compose.yml
backend/ruoyi-admin/src/main/resources/application-druid.yml
```

注意：

如果 MySQL 数据卷已经创建，仅修改 `MYSQL_PASSWORD` 不会自动修改已有数据库用户密码。需要手动进入 MySQL 修改密码，或删除 volume 后重新初始化数据库。

### 修改生产接口前缀

前端生产接口前缀在：

```text
frontend/.env.production
```

当前：

```env
VITE_APP_BASE_API = '/prod-api'
```

Nginx 需要配置同名代理：

```nginx
location /prod-api/ {
    proxy_pass http://127.0.0.1:8080/;
}
```

## 9. 上线前必须检查

上线前建议至少检查这些配置：

- 修改 `token.secret`
- 修改数据库 root 密码
- 修改数据库业务用户密码
- 修改或关闭 Druid 管理页面
- Redis 设置密码
- 检查 `ruoyi.profile` 上传目录
- 检查 `log.path` 日志目录
- 检查 `VITE_APP_BASE_API`
- 检查 Nginx `/prod-api/` 代理
- 检查防火墙和公网暴露端口
- 不要把 `.tools/`、`logs/`、`uploads/`、`node_modules/`、`dist/` 提交到 Git
