# 机加刀具信息 UI 开发范式

本文档基于当前“刀具管理 -> 刀具数据库 -> 机加刀具信息”页面的最新调整整理，用于固化后续刀具管理类页面的前端 UI 风格、交互规则和验收标准。

适用范围：

- `刀具管理` 下的物料数据库类页面。
- 具有列表、查询、新增、修改、删除、导出、提交审签等能力的管理页面。
- 需要同时展示“物料状态”和“流程状态”的审批型业务页面。

## 1. 总体视觉原则

后续同类页面默认遵循以下视觉口径：

- 整体风格：轻量、克制、低对比，不使用强烈阴影和高饱和背景。
- 页面主背景：保持 RuoYi/Element Plus 的白色内容区风格。
- 顶部页签栏：采用 Edge 风格的连体页签，不再使用独立胶囊标签。
- 查询区：首屏只保留最关键条件，详细条件折叠到弹出面板。
- 状态展示：物料状态和流程状态必须使用不同视觉体系，避免语义混淆。
- 操作按钮：按钮是否显示由权限决定，按钮是否可用由权限、选中行和业务状态共同决定。

## 2. 顶部页签标准

当前页签栏以 `frontend/src/layout/components/TagsView` 为标准实现。

### 2.1 尺寸与背景

固定标准如下：

| 项 | 标准值 |
| --- | --- |
| 页签栏高度 | `38px` |
| 单个页签宽度 | `200px` |
| 单个页签高度 | `35px` |
| 页签栏背景 | `rgb(244, 244, 244)` |
| 激活页签背景 | `rgb(255, 255, 255)` |
| 分界衬线颜色 | `rgb(243, 243, 243)` |
| 页签顶端圆角 | `13px` |
| 激活页签与背景过渡圆角 | `13px` |

### 2.2 激活页签样式

激活页签必须满足：

- 与下方页面内容视觉连为一体。
- 激活页签底部不显示独立边框。
- 激活页签顶部、左右侧、两侧圆角过渡处使用同一条细衬线。
- 不使用顶部外阴影。
- 不使用多层 `box-shadow` 模拟圆角，避免产生小方块伪影。
- 两侧连接圆角使用 `radial-gradient` 或等效方式绘制真实圆弧过渡。

### 2.3 页签内容布局

页签内容固定为：

- 文字左对齐。
- 关闭按钮右对齐。
- 文字过长时省略显示。
- 页签本身允许 `overflow: visible`，避免两侧过渡圆角被裁切。
- 文字省略应放在内部标题元素上处理，不要直接把页签容器设为 `overflow: hidden`。

## 3. 查询区标准

当前“机加刀具信息”页面的查询区以 `frontend/src/views/tooling/machiningTool/index.vue` 为标准实现。

### 3.1 首行查询

列表页顶部查询区必须固化为单行：

- 仅展示最高频、最高价值的 2 到 4 个查询条件。
- 当前基准条件为：`物料编码`、`刀具名称`、`刀具牌号`。
- 查询条件超出一行时不换行，不撑高页面。
- 查询区左侧为主查询条件，右侧固定为操作区。
- `详细查询`、`搜索`、`重置`固定在最右侧。

### 3.2 详细查询

低频条件进入“详细查询”弹出面板：

- 入口按钮文案：`详细查询`。
- 推荐使用 `el-popover`，位置 `bottom-end`。
- 面板宽度当前标准为 `360px`。
- 当前基准详细条件为：`使用状态`、`物料状态`、`流程状态`。
- 详细查询面板中每个控件宽度建议为 `220px`。
- 面板标题统一为：`更多查询条件`。

### 3.3 查询区视觉

查询区采用轻量卡片样式：

- 使用浅色渐变背景，例如 `#f8fafc -> #eef6ff`。
- 使用浅边框，例如 `#e5edf7`。
- 圆角建议 `10px`。
- 可使用极轻微阴影，但阴影不可抢视觉焦点。
- 查询区内部控件保持紧凑，避免过高。

## 4. 表格选择与工具栏标准

### 4.1 行选择规则

表格必须同时支持：

- 左侧复选框选择。
- 鼠标点击行选择。

行点击选择标准：

- 点击普通单元格时，清空旧选择并选中当前行。
- 点击复选框时，保留 Element Plus 原生多选行为。
- 点击操作按钮时，不触发行选择。
- 顶部“修改”按钮应基于当前选中行实时启用或禁用。

### 4.2 顶部按钮规则

顶部工具栏按钮标准：

| 按钮 | 显示条件 | 启用条件 |
| --- | --- | --- |
| 新增 | 具备新增权限 | 始终可点 |
| 修改 | 具备修改权限 | 仅选中 1 行且该行可修改 |
| 删除 | 具备删除权限 | 至少选中 1 行且所有选中行可删除 |
| 强制删除 | 具备强制删除权限 | 至少选中 1 行 |
| 导出 | 具备导出权限 | 始终可点 |

强制删除按钮必须遵循：

- 没有权限时不显示。
- 有权限但未选中数据时显示但禁用。
- 行内强制删除也必须只在具备权限时显示。

## 5. 状态标签标准

### 5.1 物料状态

物料状态只表示物料自身生命周期：

| 值 | 文案 |
| --- | --- |
| `draft` | 草稿 |
| `processing` | 审签中 |
| `effective` | 生效 |

物料状态可继续使用 Element Plus 原生 `el-tag` 类型：

| 状态 | 推荐类型 |
| --- | --- |
| 草稿 | `info` |
| 审签中 | `warning` |
| 生效 | `success` |

### 5.2 流程状态

流程状态只表示审签流程状态：

| 值 | 文案 |
| --- | --- |
| `draft` | 待提交 |
| `processing` | 审批流 |
| `rejected` | 驳回 |
| `effective` | 审签完成 |
| `change_processing` | 变更审批中 |
| `changing` | 变更中 |
| `change_rejected` | 变更驳回 |

流程状态必须使用不同于物料状态的配色体系。

当前标准配色：

| 状态 | 字体色 | 背景色 | 边框色 | 左侧强调色 |
| --- | --- | --- | --- | --- |
| 待提交 | `#1e3a8a` | `#eff6ff` | `#93c5fd` | `#2563eb` |
| 审批流 | `#9a3412` | `#fff7ed` | `#fdba74` | `#ea580c` |
| 驳回 | `#9f1239` | `#fff1f2` | `#fda4af` | `#e11d48` |
| 审签完成 | `#115e59` | `#ecfeff` | `#67e8f9` | `#0f766e` |
| 变更审批中 | `#5b21b6` | `#f5f3ff` | `#c4b5fd` | `#7c3aed` |
| 变更中 | `#365314` | `#f7fee7` | `#bef264` | `#65a30d` |

流程状态标签标准：

- 字体不加粗。
- 边框为 `1px`。
- 左侧强调边为 `4px`。
- 不使用刺眼高饱和底色。

## 6. 权限与状态交互标准

UI 层必须和业务规则保持一致，但不能替代后端校验。

当前“机加刀具信息”页面标准如下：

- 修改：已生效物料不可直接编辑；具备 `tooling:machiningTool:edit` 时，`effective/effective` 或 `effective/change_rejected` 行的“修改”入口用于提交修改申请。
- 变更编辑：修改申请审批通过后进入 `approvalStatus = changing`，仅 `changeApplyBy` 对应的变更申请人可以编辑并再次提交原始审签。
- 普通修改：普通申请人必须是创建人，且 `materialStatus = draft`；审核角色可修改非生效、非变更审批中的物料。
- 变更审批中：`approvalStatus = change_processing` 时不可编辑。
- 删除：普通申请人必须是创建人，且 `materialStatus = draft`；审核角色可无视物料状态。
- 提交：普通申请人必须是创建人，且 `approvalStatus in (draft, rejected)`；审核角色可代为提交。变更中的物料仅变更申请人可提交。
- 强制删除：必须具备 `tooling:machiningTool:forceRemove`，且无视物料状态。

按钮控制必须分为两层：

- `v-hasPermi` 或 `checkPermi` 决定是否显示。
- `canEdit`、`canDelete`、`canSubmit` 等业务函数决定是否可操作。

## 7. 表单与弹窗标准

新增、修改弹窗标准：

- 宽度当前建议 `720px`。
- 表单标签宽度当前建议 `110px`。
- 常规字段两列布局，每列 `12` 栅格。
- `版本`、`物料状态`、`流程状态`只展示，不允许普通编辑。
- 新建物料显示初始版本 `A01`，版本字段不可手工修改。
- 新增保存成功提示必须明确“物料已保存为草稿”。
- 提交审批使用独立弹窗，不与新增/修改表单混合。

提交审批弹窗标准：

- 宽度当前建议 `520px`。
- 物料编码、刀具名称只读。
- 版本只读。
- 提交意见使用 textarea。
- 提交成功后刷新列表。

修改申请弹窗标准：

- 宽度沿用提交审批弹窗。
- 物料编码、版本、刀具名称只读。
- 意见字段文案使用“申请说明”。
- 提交成功后状态进入 `change_processing`。

历史版本弹窗标准：

- 行内提供“历史版本”入口。
- 弹窗展示完整版本快照，包括版本、物料编码、刀具名称、业务字段、物料状态、流程状态、快照人和快照时间。
- 仅查看，不提供编辑、回滚、导出和差异对比。

## 8. 文件落点标准

当前基准文件：

```text
frontend/src/views/tooling/machiningTool/index.vue
frontend/src/layout/components/TagsView/index.vue
frontend/src/layout/components/TagsView/ScrollPane.vue
frontend/src/layout/components/AppMain.vue
```

后续同类页面如果只涉及业务列表布局，优先改业务页面。

只有当需求影响全局页签、主布局高度、页签滚动行为时，才允许修改 `TagsView`、`ScrollPane`、`AppMain`。

## 9. 验收清单

后续同类页面 UI 完成后，至少检查：

1. 页签栏高度为 `38px`，页签尺寸为 `200px x 35px`。
2. 激活页签背景为白色，并与下方页面连为一体。
3. 页签栏背景为 `rgb(244, 244, 244)`。
4. 页签衬线为 `rgb(243, 243, 243)`，且没有顶部双线。
5. 页签圆角过渡处没有小方框。
6. 查询区首行不换行，右侧按钮固定在最右边。
7. 详细查询条件位于弹出面板中。
8. 点击表格行可以选中该行，并正确启用“修改”等顶部按钮。
9. 点击复选框仍保留多选能力。
10. 点击行内按钮不触发行选择。
11. 物料状态与流程状态配色体系不同。
12. 流程状态字体不加粗。
13. 强制删除按钮仅在具备权限时显示。
14. 列表展示“版本”列，表单展示只读版本。
15. 已生效物料点击“修改”进入修改申请弹窗，不直接进入编辑表单。
16. 变更审批通过后，仅变更申请人可编辑并提交。
17. 历史版本弹窗可查看已生效版本快照。
18. 前端构建通过。

## 10. 后续执行口径

后续刀具管理类页面默认按本文档执行。

如果业务确实需要偏离本文档，必须在需求或交付说明中明确写出偏离项、原因和影响范围；否则视为应按当前“机加刀具信息”页面标准实现。
